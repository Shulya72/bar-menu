# Дизайн и история

Здесь только материалы. На сайт эта папка не выкладывается: Worker раздаёт лишь `public/`.

## redesign-v4 — макет «Слоновая кость и бордо»

- **Главный файл — `page.html`.** Открывается в браузере и рисует все 24 экрана: гость и бармен, день и вечер.
- **Откуда берутся экраны:** их строит `screens.js` из `data.js`. В `data.js` лежит меню сайта на 17.10.2026: названия, описания, цены, состав.
- **Скриншоты:** `node design/redesign-v4/shoot.mjs` снимает каждый экран в `design/redesign-v4/shots/` (390×844 @2x). Скрипты рассчитаны на среду Claude: Playwright и Chromium по путям в `/opt`.
- **Доски для согласования:** `board.html` и `board.mjs`; готовые доски лежат в `boards/`.
- **Логотип:**
  - `via-logo-original.png` — исходник;
  - `via-logo-bordeaux.png` — для светлой темы;
  - `via-logo-gold.png` — для тёмной.
- **Фото коктейлей:**
  - `photos/gemini/` — новые снимки Владимира из Gemini;
  - `photos/bar/` — временные, для остальных коктейлей.
- **`fonts/`** — Cormorant Garamond и Manrope (SIL Open Font License).

## history — книга «История создания приложения VIA Family Bar»

- **Сборка:** `node design/history/make.mjs` создаёт `design/history/VIA-Family-Bar-история-создания.pdf`: 111 страниц, закладки, кликабельное содержание. Нужен `pypdf`.
- **Как устроена:**
  - вёрстка — `kniga.html`;
  - тексты вариаций — `v1.js`…`v4.js`;
  - экраны — `img/`.
- **Чтобы добавить новую главу:** допиши в `v4.js` (или заведи `v5.js` и подключи его в `kniga.html`) и пересобери.
- **`capture/`** — скрипты, которыми 18.10.2026 сняты экраны старых вариаций со старых версий кода. Для истории: пути внутри указывают на временные папки той сессии.
