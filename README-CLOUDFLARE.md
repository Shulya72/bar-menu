# Бар — новая Cloudflare версия

Это новая версия проекта «Бар». Старые index.html и barmen_list.html сохранены как исторический прототип.

## Архитектура
- Cloudflare Worker — приложение и API
- Cloudflare D1 — база данных
- Cloudflare R2 — фотографии (подключим позже)
- GitHub — исходный код

## Правило
Книга рецептов бармена является источником данных. Публичная «Карта бара» получает только безопасные для гостя поля.
