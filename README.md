# VIA Bar

Домашний бар Владимира и Анастасии: **https://shulya.party**

- `/menu` — гостям: меню коктейлей, заказ, профиль и оценки.
- `/bar` — бармену: заказы, рецепты, склад, закупки, статистика.

Как устроен сайт:
- Cloudflare Worker (`src/`) и статика (`public/`).
- База D1 и хранилище фото R2.
- Выкладка идёт сама после каждого изменения в `main` (GitHub Actions).

| Где | Что |
|---|---|
| `src/` | Код сайта |
| `public/` | Иконки, шрифты, манифесты, офлайн-помощник |
| `design/redesign-v4/` | Макет нового дизайна «Слоновая кость и бордо» |
| `design/history/` | Книга «История создания приложения VIA Family Bar» |
| `CLAUDE.md` | Подробная памятка: устройство, правила, бэкапы, статус |
| `index.html` | Переадресация со старого адреса на GitHub Pages |

Бэкап данных: Actions → **Backup data** → Run workflow.
